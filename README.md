# Коннектом выбора

**Нейросеть, построенная из настоящих нейронов мозга дрозофилы, решает, примет ли самка ухаживающего самца — и показывает, какие нейроны при этом работают.**

Проект для конкурса по биологии и программированию. Модель создана и обучена с нуля: готовые или предобученные ИИ-модели не используются. PyTorch служит только «калькулятором» для обучения, а работающая модель исполняется в браузере на собственном коде на JavaScript.

---

| Что | Как |
|---|---|

Без интернета вместо фирменных шрифтов используются системные, всё остальное работает.

## Идея в двух словах

1. **Мозг.** Берём открытый коннектом FlyWire — полную карту мозга самки *Drosophila melanogaster*, восстановленную по электронной микроскопии: ~139 000 нейронов, ~50 млн синапсов.
2. **Цепь.** Алгоритм «потока сигнала» вырезает из него цепь выбора партнёра: от органов чувств (слух, обоняние, сигнал о спаривании) до нейронов решения. Получается **978 нейронов, 9 967 связей, 173 750 синапсов**.
3. **Нейросеть.** Каждый нейрон цепи — узел сети, каждая связь — реальная синаптическая связь со знаком по медиатору (ацетилхолин +, ГАМК/глутамат −) и силой по числу синапсов. Сеть не может добавить связь, которой нет в мозге.
4. **Обучение.** Сеть учится на опубликованных экспериментах: 28 поведенческих опытов (какая доля самок спаривается в каких условиях) и 15 физиологических фактов (какие нейроны отвечают на что). Шесть опытов спрятаны от сети и служат честным тестом.
5. **Визуализация.** Веб-приложение на русском: меняете условия (вид самца, его песня, феромон, возраст и статус самки, «выключение» нейронов), а в 3D-мозге загораются нейроны. Модель выдаёт решение, его вероятность и объяснение, какой путь сигнала к нему привёл.

## Что умеет модель

- **Распознаёт песню своего вида.** Самец D. melanogaster поёт с интервалом между импульсами ~35 мс, D. simulans — ~48 мс. Слуховые нейроны vpoEN в модели настроены на 35 мс, и самка отвергает «чужую» песню.
- **Помнит о спаривании.** Половой пептид из семени самца выключает восходящие нейроны SAG → слабеет «центр желания» pC1 → нейроны vpoDN перестают открывать путь. Через несколько суток восприимчивость возвращается.
- **Учитывает возраст.** Молодые самки (до ~1,5 сут) не спариваются: гормональный сигнал (экдизон → лейкокинин) тормозит pC1.
- **Отвечает на феромон самца** cVA через обонятельные нейроны Or67d.
- **Виртуальная оптогенетика.** Можно «выключить» или «включить» любую ключевую группу нейронов и сравнить результат с настоящими опытами.
- **Активный отказ.** Спарившаяся самка отвечает выдвижением яйцеклада через нейроны DNp13.

## Ключевые нейроны (названия из FlyWire)

| Группа | Нейроны FlyWire | Роль |
|---|---|---|
| Слух | JO-A, JO-B (Джонстонов орган) | слышат песню самца |
| Детектор песни | vpoEN | отвечают на ритм ~35 мс |
| Детекторы песни | pC2l (AVLP567–570, CL313 и др.) | импульсная песня |
| Обоняние | ORN_DA1 (Or67d), ORN_DL3 (Or65a) | феромон cVA |
| Сигнал «девственница» | SAG (AN_SMP_2) | от половых путей, гаснет после спаривания |
| Центр желания | pC1a, pC1b, pC1c | объединяют песню, феромон и статус |
| Торможение | AVLP008 (ГАМК) | второй по силе вход vpoDN |
| Решение «да» | vpoDN (DNp37) | открывают вагинальную пластинку |
| Решение «нет» | DNp13 | выдвижение яйцеклада |

## Структура репозитория

```
pipeline/            код на Python (запускать по порядку)
  config.py          настройки, группы нейронов
  01_download.py     скачивание данных FlyWire
  02_build_circuit.py выделение цепи из коннектома
  03_build_dataset.py обучающие данные из статей (с источниками)
  model.py           коннектомная нейросеть (PyTorch)
  04_train.py        обучение и проверка
  05_skeletons.py    3D-форма нейронов для визуализации
  06_export_web.py   экспорт модели в веб-приложение
  07_build_bundle.py сборка в один html-файл
data/literature/     обучающая выборка (JSON, русские описания и ссылки)
data/processed/      выделенная цепь и упрощённые скелеты (маленькие файлы)
models/              обученные веса и отчёт
web/                 веб-приложение (HTML/CSS/JS, без внешних библиотек)
dist/                приложение одним файлом
docs/                материалы для защиты проекта
```

## Как повторить с нуля

```bash
pip install -r requirements.txt
python pipeline/01_download.py --skeletons   # ~6.3 ГБ, скелеты нужны только для 3D
python pipeline/02_build_circuit.py
python pipeline/03_build_dataset.py
python pipeline/04_train.py --iters 600      # ~20 минут на обычном процессоре
python pipeline/05_skeletons.py
python pipeline/06_export_web.py
python pipeline/07_build_bundle.py
```

## Ограничения

- FlyWire — мозг одной самки, без брюшной нервной цепочки. Сигналы, приходящие из тела (SAG, гормоны), заданы как входы модели.
- Модель описывает частоту разрядов нейронов, а не отдельные спайки; действие нейромодуляторов упрощено.
- Данные из статей заданы интервалами, потому что результаты разных лабораторий различаются.
- Возрастной сигнал и спад действия полового пептида со временем — модельные допущения, основанные на статьях (Chen et al., 2025; Peng et al., 2005).
