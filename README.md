# Коннектом выбора

**Нейросети, построенные из настоящих нейронов дрозофилы, решают, примет ли самка ухаживающего самца и станет ли самец ухаживать, и показывают, какие нейроны при этом работают.**

Проект для конкурса по биологии и программированию. Модели созданы и обучены с нуля: готовые или предобученные ИИ-модели не используются. PyTorch служит только «калькулятором» для обучения, а работающая модель исполняется в браузере собственным кодом на JavaScript.

---

## Как открыть

| Что | Как |
|---|---|

| Версия для разработки | `web/index.html` (подгружает файлы из `web/js` и `web/data`). |

Без интернета вместо фирменных шрифтов используются системные моноширинные, всё остальное работает.

## Идея в двух словах

1. **Нервная система.** Берём открытые коннектомы — полные карты нейронов и синапсов, восстановленные по электронной микроскопии:
   * **самка** — FlyWire 783, мозг самки *Drosophila melanogaster* (~139 000 нейронов);
   * **самец** — MaleCNS v1.0, мозг и брюшная нервная цепочка самца (~166 000 нейронов).
2. **Цепь.** Алгоритм «потока сигнала» вырезает из коннектома цепь от органов чувств до нейронов решения:
   * самка: **978 нейронов, 9 967 связей, 173 750 синапсов**;
   * самец: **1 382 нейрона, 45 011 связей, 800 829 синапсов**.
3. **Нейросеть.** Каждый нейрон цепи — узел сети, каждая связь — реальная синаптическая связь со знаком по медиатору (ацетилхолин +, ГАМК/глутамат −) и силой по числу синапсов. Сеть не может добавить связь, которой нет в нервной системе.
4. **Обучение.** Сети учатся на опубликованных экспериментах: какая доля мух спаривается или ухаживает в каких условиях, и какие нейроны отвечают на что. Часть опытов спрятана от сети и служит честным тестом.
5. **Визуализация.** Веб-приложение на русском: меняете условия (вид самца, песня, феромоны, возраст и статус самки, мутации, «выключение» нейронов), а в 3D-модели загораются нейроны. Модель выдаёт решение, его вероятность, объяснение и путь сигнала.

## Что умеют модели

**Самка**
- Распознаёт песню своего вида: интервал между импульсами ~35 мс у D. melanogaster и ~48 мс у D. simulans. Нейроны vpoEN в модели настроены на 35 мс, и «чужую» песню самка отвергает.
- Помнит о спаривании: половой пептид из семени самца выключает нейроны SAG → слабеет «центр желания» pC1 → нейроны vpoDN перестают открывать путь. Через несколько суток восприимчивость возвращается.
- Учитывает возраст: молодые самки не спариваются, гормональный сигнал (экдизон → лейкокинин) тормозит pC1.
- Отвечает на феромон самца cVA через обонятельные нейроны Or67d; спарившаяся самка активно отказывает через DNp13.

**Самец**
- Пробует цель лапками: феромон самки 7,11-HD (F-клетки ppk23/ppk25) ведёт к P1 через vAB3 и PPN1, а 7-трикозен самцов (M-клетки) возбуждает тормозные нейроны mAL.
- Чует cVA — «метку соперника» на спарившейся самке и на самцах — и ухаживает меньше.
- Следит за движущейся целью зрительными нейронами LC10a; в темноте ухаживает слабее.
- После серии спариваний мотивация (дофамин → P1) падает.
- Решение «ухаживать» — нейроны P1, команда «петь» — pIP10 и генератор песни в грудных ганглиях.

## Результаты обучения

| Модель | Опыты обучения в интервале статьи | Скрытые тестовые опыты | Физиологические факты | Совпадение браузера и PyTorch |
|---|---|---|---|---|
| Самка (FlyWire) | 22 из 22 | 4 из 6 | 15 из 15 | расхождение < 0,0001 |
| Самец (MaleCNS) | 9 из 9 | 2 из 3 | 10 из 10 | расхождение < 0,0001 |

Ошибки на тестах мы показываем открыто:
- **Самка, выключение pCd.** В статье Zhou et al. (2014) самки становятся невосприимчивыми, в модели — почти нет: в выделенной цепи pCd слабо связаны с нейронами решения.
- **Самка, активация SAG у спарившейся.** Восприимчивость возвращается, как в статье, но чуть сильнее верхней границы.
- **Самец, мутант Gr32a.** В опытах такие самцы ухаживают за самцами, а в модели нет: запах cVA соперника продолжает тормозить P1.

Подробности по каждому опыту — во вкладке «Обучение и проверка» и в `models/*_report.json`.

## Структура репозитория

```
pipeline/                 код на Python (запускать по порядку)
  config.py               настройки, группы нейронов самки и самца
  01_download.py          скачивание данных FlyWire и MaleCNS
  02_build_circuit.py     цепь самки из FlyWire
  02b_build_circuit_male.py цепь самца из MaleCNS
  03_build_dataset.py     обучающие данные самки (с источниками)
  03b_build_dataset_male.py обучающие данные самца
  model.py                коннектомная нейросеть (PyTorch), общая для обоих полов
  04_train.py             обучение и проверка (--sex female|male)
  05_skeletons.py         3D-форма нейронов самки
  05b_skeletons_male.py   3D-форма нейронов самца
  skeleton_utils.py       упрощение скелетов
  06_export_web.py        экспорт моделей в веб-приложение
  07_build_bundle.py      сборка в один html-файл
data/literature/          обучающие выборки (JSON, русские описания и ссылки)
data/processed/           выделенные цепи и упрощённые скелеты (маленькие файлы)
models/                   обученные веса и отчёты
web/                      веб-приложение (HTML/CSS/JS, без внешних библиотек)
dist/                     приложение одним файлом
docs/                     материалы для защиты проекта
```

## Как повторить с нуля

```bash
pip install -r requirements.txt
python pipeline/01_download.py --skeletons --male   # ~6.9 ГБ; скелеты самки нужны только для 3D
python pipeline/02_build_circuit.py
python pipeline/02b_build_circuit_male.py
python pipeline/03_build_dataset.py
python pipeline/03b_build_dataset_male.py
python pipeline/04_train.py --sex female --iters 600   # ~20 минут на обычном процессоре
python pipeline/04_train.py --sex male --iters 600     # ~20 минут
python pipeline/05_skeletons.py
python pipeline/05b_skeletons_male.py
python pipeline/06_export_web.py
python pipeline/07_build_bundle.py
```

Модель самки в репозитории обучалась в два этапа: 600 шагов, затем исправление одной цели в данных (выдвижение яйцеклада отпугивает самца только у спарившихся самок, Wang et al., 2020) и ещё 500 шагов (`--resume`).

## Ограничения

- Коннектом самки — только мозг; сигналы из тела (SAG, гормоны) заданы как входы. Коннектом самца включает нервную цепочку, но гормоны и нейромодуляторы тоже упрощены.
- Модель описывает частоту разрядов нейронов, а не отдельные спайки.
- Данные из статей заданы интервалами, потому что результаты разных лабораторий различаются.
- Возрастной сигнал самки, спад действия полового пептида и уровни феромонов на разных целях — модельные допущения, основанные на статьях.
- Предсказанные медиаторы не всегда совпадают с описаниями в статьях (например, vAB3 в MaleCNS предсказаны ГАМК-ергическими). Модель следует коннектому.
